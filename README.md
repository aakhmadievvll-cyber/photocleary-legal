# PhotoCleary — legal & support pages

Public legal and support pages for PhotoCleary / Фоточистка, served with GitHub Pages:

- https://aakhmadievvll-cyber.github.io/photocleary-legal/
- https://aakhmadievvll-cyber.github.io/photocleary-legal/privacy.html
- https://aakhmadievvll-cyber.github.io/photocleary-legal/terms.html
- https://aakhmadievvll-cyber.github.io/photocleary-legal/support.html

Static HTML only: no cookies, analytics or scripts. GitHub Pages publishes `main` from `/`.
The iOS repository keeps the same HTML and CSS in `Legal/`; update both when changing the site.

`privacy-v1.1.html` preserves the historical policy text and effective date for version 1.1.0,
including its historical product name. It is archived under the current site URL and excluded
from search indexing. The policy text and data practices were not changed by this URL migration.

The former site contains only compatibility redirects for already installed app versions.
All new app and App Store links must use the canonical URLs above.
